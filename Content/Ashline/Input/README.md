# Input

**You do not need to create these assets to Play.** `UAshlineRuntimeInput` builds
Input Actions and Mapping Contexts in memory on possess.

Optional editor copies (same names) can be generated with
`Scripts/create_ashline_play_assets.py` if you want to tweak binds in the asset editor.

**Mapping contexts**

- `IMC_Ashline_KBM`
- `IMC_Ashline_Gamepad`
- `IMC_Ashline_Touch`

**Actions**

- `IA_Move` (Axis2D)
- `IA_Look` (Axis2D)
- `IA_Jump`, `IA_Fire`, `IA_Aim`, `IA_Reload`, `IA_CameraToggle`, `IA_SwapWeapon`, `IA_Crouch` (Digital)
